# Ventrovia international migration

Ventrovia is an English-language, worldwide industrial sourcing and
manufacturer knowledge website. The canonical domain is
`https://ventroviaglobal.com`; the company base is Dubai, UAE.

## Permanent runtime boundary

The web repository and every deployment are manufacturer-only. They contain no
SKU database, product-search index, product route, product API, product
structured data or product-level administration. A private owner-held legacy
dataset is outside the repository and is not required to install, test, build
or deploy Ventrovia.

The public acquisition surface is:

- Home, About and Contact;
- the 2,806-record manufacturer directory;
- source-verified English manufacturer pages;
- specification-led RFQ forms.

## Brand Knowledge

Manufacturer identity, category and family statements must be backed by a
manufacturer-owned source. Source verification and English content readiness
remain separate gates. Only `BRAND_SAFE` English profiles enter the sitemap.

## Contact and infrastructure

The centralized brand configuration contains the Dubai address, international
telephone number and `sales@ventroviaglobal.com`. RFQ delivery must fail visibly
until verified mail infrastructure is configured. DNS, MX and custom-domain
changes require a separate owner-approved operation.
