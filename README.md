# Ventrovia

International manufacturer knowledge base and industrial RFQ website for
`https://aihamyn.ae`. Next.js 16 (App Router), React 19, TypeScript.

## What the site contains

- Home, Services, About, Contact and Privacy pages in English.
- `/manufacturers` — 2,395 manufacturers with verified English profiles and
  2,090 reviewed logos. Manufacturer pages are generated from
  `data/brand-knowledge-international/profiles.json`.
- Specification-led RFQ forms (`/api/request`).
- A password-protected admin area (`/admin`) with editable site copy and the
  Brand Health dashboard.

The repository is brand-only: it holds no product catalog, product data or
product routes.

## Getting started

```bash
pnpm install --frozen-lockfile
pnpm dev            # local development server
pnpm check          # lint, typecheck, build, tests and audits
```

Copy `.env.example` to `.env.local` for local secrets. Nothing works without
`ADMIN_PASSWORD` and `ADMIN_SESSION_SECRET` for the admin area; the RFQ form
fails visibly until `RESEND_API_KEY` and the mail addresses are configured
(see `docs/EMAIL_SETUP.md`).

## Project layout

| Path | Purpose |
| --- | --- |
| `app/` | Next.js routes, components and server-side libraries |
| `app/generated/` | Generated manufacturer directory — do not edit by hand |
| `content/site-content.json` | Editable page copy (also editable from `/admin`) |
| `data/manufacturers/` | Identity index of all manufacturers |
| `data/brand-sources/` | Reviewed manufacturer-owned source facts (input) |
| `data/brand-knowledge-international/` | Generated public English profiles |
| `data/brand-operations/` | Generated brand-health reports (admin only) |
| `public/images/brand-logos/` | Reviewed publishable logos, registered in `app/lib/brand-logos.ts` |
| `brand-master/` | Portable brand data package generated by `pnpm brands:master` |
| `scripts/` | Data generation, logo tooling and audits |
| `tests/` | Node test suite run against the built bundle |
| `docs/` | Deployment, email, brand asset and data governance notes |

## Regenerating brand data

Source facts live in `data/brand-sources/`. After editing them run, in order:

```bash
pnpm brands:directory      # data/manufacturers -> app/generated/manufacturer-directory.ts
pnpm brands:international  # brand sources -> public English profiles
pnpm brands:operations     # brand-health reports for the admin dashboard
pnpm brands:master         # portable brand-master package
```

`pnpm prebuild` runs the `--check` variants and fails the build when any
generated file is stale.

## Builds

- `pnpm build:timeweb` / `pnpm start:timeweb` — the production build used on
  Timeweb App Platform (`next build`).
- `pnpm build` / `pnpm start` — the Worker bundle (`vinext`) used by the test
  suite and the Sites mirror.
